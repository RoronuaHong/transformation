## 2. 逐项验证(外部标准 → 本项目落地 → 验证方法 → 结果)

### A. 集中存储 / 单一可信源
- **外部标准**(Cloudinary,Canto #1):所有数字资产集中一处,作为单一可信源;上传即带必填元数据。
- **本项目落地**:SQLite 索引 `index/hub.db` 为统一目录;`internal` 文件移入 `materials/<kind>/`,`external` 仅记 `external_path`(不复制,省盘);`bridge_subtitle.py` 只读聚合上游。
- **验证方法**:`core.all_materials()` 数量 == 128(2026-10-09 语料重构后);`core.HUB` 为单一根;断言 `internal` 与 `external` 两种 location 都可被检索。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### B. 组织与分类(kind + 逻辑结构)
- **外部标准**(Canto #2/#8):按项目/活动组织而非按类型;视频需版本与拍摄元数据。
- **本项目落地**:`classify()` 按扩展名分 8 类(kind);`tags` 用受控词表 `sp/job:/type:/role:/lang:` 表达项目归属(如 `job:BV1aDb56iEvu`)。
- **验证方法**:对 样本文件跑 `core.classify()` 验证分类正确;`facets()` 返回 `type:`/`lang:` 分面;断言 `job:` 能筛出某 B 站视频全套素材。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### C. 元数据分类法 / 受控词表
- **外部标准**(Cloudinary"一致分类法是 AI 检索成败最大因素";Adobe"受控词表预定义术语集防同义碎片")。
- **本项目落地**:`QUERY_SYNONYMS` 受控同义词表(中文→语料英文词,如 `去台标→delogo`、`去马赛克→demosaic`);标签 `key:value` 受控词汇。
- **验证方法**:`core.expand_query("去除视频里的台标")` 必须展开出 `delogo`;`core.expand_query("去马赛克")` 展开出 `demosaic`;断言展开词能命中对应成品。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### D. 元数据字段与模式
- **外部标准**(Adobe:名称/类型/位置/修改时间/标签 + 技术/描述/管理三类)。
- **本项目落地**:`materials` 表含 `id/name/kind/tags/description/external_path/rel_path/location/size/mtime/sha256/...`;技术字段由摄入自动生成。
- **验证方法**:`core.get_material(id)` 返回名称/类型/位置/标签;断言 `facets()` 含 `type:`/`lang:`/`role:` 分面。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### E. AI 自动增强元数据
- **外部标准**(Cloudinary"AI 增强";Canto #4 视觉搜索/智能标签/OCR/近重复)。
- **本项目落地**:`auto_process` 自动链:封面(ffmpeg)、**画面 OCR**(rapidocr→sidecar)、镜头索引(shots)、感知哈希(dHash)、视觉向量(CLIP)、文本向量(bge-m3)。
- **验证方法**:对一条视频 `run_ocr` 后断言 `index/ocr/<id>.txt` 生成;`build_image_embeddings` 后 `image_embeddings` 行数增长;`near_duplicate_report` 返回近重复对。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### F. 检索与发现(词法+语义+过滤)
- **外部标准**(Cloudinary"高级过滤+语义意图理解";Canto #4)。
- **本项目落地**:词法(中文 bigram/英数 token + 字段加权 + 同义词 + 长词松匹配)+ 语义(bge-m3)+ RRF 融合;支持 `kind=`/`tag=` 过滤。
- **验证方法**:中文 `去除字幕只留背景`→命中 `dehardsub_meta.json`;按 `kind=videos` 过滤只返回视频。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### G. 跨语检索
- **外部标准**:多语 / 跨语理解(本项目差异化的增强项)。
- **本项目落地**:`translategemma:4b` 跨语桥接——英文查询译中后中英合并检索(`core._maybe_translate`)。
- **验证方法**:英文 `detect and remove watermarks from video`→命中 `*_delogo.mp4`;`restore and deblur a low-quality face`→`deblurred_*`。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### H. 访问与权限控制
- **外部标准**(Cloudinary"可定制/细粒度权限";Canto #6 角色)。
- **本项目落地**:`external_path_allowed()` 白名单(工作区根 + `VITUAL_HUB_EXT_ROOTS`);`/api/file` **双校验**(core + server);`VITUAL_HUB_TOKEN` 鉴权;`VITUAL_HUB_HOST` 默认 127.0.0.1。
- **验证方法**:`core.external_path_allowed("/etc/passwd")`==False;`external_path_allowed(HUB 内路径)`==True;server `/api/file?path=/etc/passwd` 返回 403。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### I. 引用完整性与安全(外链不复制)
- **外部标准**(proxyless 外部引用,安全清理铁律)。
- **本项目落地**:`broken_externals()` 检测失效外链;`prune_broken_externals()` 只删索引绝不碰磁盘;`/api/health` 报告失效数;越界读取统一 403。
- **验证方法**:构造一个指向不存在文件的外部素材,`broken_externals()` 能检出;`prune` 后索引消失但原文件不受影响(本测试不实际删除,改断言逻辑)。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### J. 版本 / 溯源 / 审计
- **外部标准**(Cloudinary"历史追踪+审计";Adobe"审计记录+数据血缘")。
- **本项目落地**:`history` 审计表记录写操作(app/ocr/describe/remove…);`hub://history` Resource;OCR/打标变更可审计。
- **验证方法**:执行一次 `update_material`(写入描述),`log_history` 后 `history_audit()` 能查到该记录。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### K. 去重
- **外部标准**(Canto #7 定期审计去重归档)。
- **本项目落地**:SHA-256 去重(`sha256` 字段 + `dupes` 工具);`near_duplicate_report` 画面级 dHash 近重复。
- **验证方法**:`near_duplicate_report()` 返回结构含 `pair_count`/`cluster_count`;`core.dupes()` 按哈希分组。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### L. 治理与合规
- **外部标准**(Canto #6 角色治理;Cloudinary C2PA 溯源/合规;Adobe 治理)。
- **本项目落地**:`governance_report`(占位/缺描述/未分类/无标签);Agent 写操作 `confirm=true` HITL;门禁回归。
- **验证方法**:`governance_report()` 返回分类统计;Agent 无 `confirm` 的写任务被拒。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### M. 自动化工作流
- **外部标准**(Cloudinary"工作流自动化";Canto #5 标准化流程)。
- **本项目落地**:`enqueue_autoproc` 事件驱动自动处理;`bridge_subtitle.py --auto --embed --prune` 上游联动;摄入即自动跑 OCR/封面/镜头。
- **验证方法**:断言 `core.enqueue_autoproc` 存在且幂等;`bridge_subtitle.run_job_dir` 可被调用(只读扫描)。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### N. Agentic DAM(感知-推理-行动)
- **外部标准**(Agentic AI:Canto 未提,但行业共识——自主 Agent 能感知环境、推理、行动并带 HITL)。
- **本项目落地**:Deep Agent `agent_run`——感知(search/related/shots)→ 推理(多查询检索+LLM 汇总)→ 行动(assemble/deliver);带 **HITL confirm**、**确定性 Critic**(防幻觉 id)、**诚实弃权**(0 命中)、**跨任务记忆 playbook**、**结构化引用 citations**、**长任务滚动摘要**、**协作式取消**。
- **验证方法**:跑 `tests/test_agent_eval.py` 5 个场景全绿;断言无 `confirm` 的写任务被拒;断言 0 命中任务如实说明而非编造 id。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### O. 检索质量评估
- **外部标准**(RAG 评估:人工标注 GT + Precision@K/Recall@K/MRR/NDCG + 回归门禁)。
- **本项目落地**:`eval_ground_truth.json`(16 查询/427 标注/249 唯一 id);`eval_search.py --gate` 基线 p5 .71/r20 .78/mrr .85/ndcg .84(容差 0.02)。
- **验证方法**:跑 `eval_search.py --mode lexical --gate` → GATE PASS。
- **结果**:**PASS**(全场景实例覆盖验证 34/34,见 §3)

### P. 可观测性
