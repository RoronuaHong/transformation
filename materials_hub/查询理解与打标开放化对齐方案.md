# 查询理解与打标开放化 · 对齐最佳实践

> 背景:评审指出 `tag_vocab`(打标白名单)与 `QUERY_SYNONYMS`(查询同义词)是**写死的业务表**,
> 不可扩展、无缩写归一、弱多语。本文记录对齐"受控词表 + 开放词汇"最佳实践的改造。
> 原则:**数据驱动(只收语料真实 token)+ 受控(tag_vocab 零幻觉)与开放(VLM/open)分层 +
> 全程可开关 + 检索回归门禁防退化**。

## 1. 三层现状与缺口

| 层 | 机制 | 缺口(评审指出) |
|---|---|---|
| 打标 | `tag_vocab` 封闭白名单 + SigLIP2 zero-shot(零幻觉主力) | 封闭:tag_vocab 之外的实体全丢,新题材只能手改词表 |
| 查询同义 | `QUERY_SYNONYMS` 中文→英文语料同义词 | 纯英文查询"原样返回":4K/GPU/语音识别 等缩写无法归一 |
| 多语 | `_maybe_translate`(translategemma 译中)+ bge-m3 多语向量 | 不在词表/同义词层;译不准则召回弱。**不写死多语表**(避免又一张封闭业务表) |

## 2. 已落地

### 2.1 查询归一层(commit 13cfe62)—— 补缩写/简称
- 新增 `QUERY_ABBREV`:英文缩写(4K/8K/GPU…)**词边界匹配**(防 `said` 误中 `ai`)+ 中文简称
  (超清/超分辨率/语音识别/文字识别/帧率/界面),展开到**语料真实 token**(upscale/esrgan/asr/ocr/gpu)。
- `expand_query` 由"纯英文原样返回"改为**中英都归一**;只加词不改词;多语仍走翻译桥接。
- 门禁:`eval_search --mode lexical --gate` **GATE PASS**(p5/r20/mrr/ndcg 全 0 delta,零回归)。
- 数据驱动:只收语料存在的英文词 + 明确概念缩写,非无限业务封闭表。

### 2.2 打标开放化(本次)—— open 通道,零幻觉主力不变
- 原 `build_auto_tags` 的 VLM 画面描述**只用于验证** SigLIP2 标签,VLM 里 tag_vocab 之外的
  具体实体被丢弃(打标封闭的实证)。
- 新增 `_open_entities`:从 VLM 英文描述抽 **tag_vocab 之外**的具体实体,归一层控噪
  (停用词 / 泛化黑名单 food·thing·scene·object… / 长度≥3 / 去重 / 去 tag_vocab 已覆盖单词),
  入 autotag sidecar `open` 字段;`_autotags_text` 纳入 open 补召回。
- **SigLIP2×tag_vocab 零幻觉主力(verified/auto)完全不变**;open 仅低权重补充,绝不进
  description(排序稀释铁律)。`VITUAL_OPEN_TAG=0` 可关。
- 门禁:现有 sidecar 无 open → 当前 **GATE PASS(零副作用)**;open 的检索增益需
  `cli.py vtag --force` 重建后用 auto/lexical 门禁实测(见 §4)。

## 3. 设计原则(为何不是又一张写死表)

- **受控与开放分层**:tag_vocab = 受控(零幻觉、可解释、做分面);open/VLM = 开放(补召回、
  低权重、归一层过滤)。不是把可选标签锁死在人工表内。
- **数据驱动**:缩写/同义只收语料真实 token(沿用 QUERY_SYNONYMS 哲学),可挖掘扩充而非手堆。
- **多语不写表**:靠翻译桥接 + 多语向量,避免第三张封闭业务表。
- **全程可开关 + 门禁**:每次改动跑 `eval_search --gate`,掉出基线即报。

## 4. 待验证 / 后续

1. **重建 vtag 实测 open 增益**:`cli.py vtag --force` 后跑 `eval_search --gate`(lexical/auto),
   对比 R@20 是否提升、P@5 是否保持;若 P@5 退化,把 open 移出主词法或再降权。
2. **缩写库数据挖掘扩充**:从语料高频 token + 通用缩写库挖掘,而非手写。
3. **多语标签(可选)**:若需标签侧多语,经翻译桥接生成,不写死多语词表。
4. **受控词表增长治理**:`core.distinct_tags()` 定期审计,open 高频实体可晋升进 tag_vocab
   (开放→受控的正向循环)。
