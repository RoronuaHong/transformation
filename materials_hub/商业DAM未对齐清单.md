# 商业 DAM 最佳实践 · 未对齐清单

> 对照对象：上一轮列出的 Cloudinary MAM 2026、Canto Top 10、Adobe 元数据、检索评估四份公开做法。
> 核对日期：2026-10-08。只列还没对齐或只对齐了一部分的条目。
> [素材中心最佳实践对照验证报告.md](素材中心最佳实践对照验证报告.md) 把 A–R 都标成 PASS。那份报告验的是「本项目有没有对应功能」，下面验的是「和商业产品原文是否同一件事」。两份可以同时成立。

已对齐、这里不重复：单一索引、受控词表、混合检索和回归门禁、写操作留痕、外链不复制、去重、入库自动处理、MCP / CLI / 面板。

## 未对齐

1. **资产版本。** Canto、Cloudinary、Adobe 都要求能回到上一版已审批文件。本库更新会覆盖索引；`history` 只记谁改了标签或描述，不保留文件本体的旧版本。`trash/` 只回收索引。
2. **权利与到期。** Cloudinary 的治理包含授权范围、到期日、C2PA 内容溯源。库里没有权利字段，也没有到期提醒。素材目前都是自己做的，所以还没踩到，但和商业条目不是同一件事。
3. **角色权限。** Canto 把人分成管理员、贡献者、使用者。Cloudinary 要求可定制的细粒度权限。现在只有一把可选的 `VITUAL_HUB_TOKEN`，有令牌就能读写。跨机器时文档写了要升到 OAuth，代码里没有。
4. **人脸识别。** Canto 的 AI 四件套是视觉搜索、智能标签、OCR、人脸。前三件有sidecar 或向量。人脸没有检测、没有人名库。
5. **按项目浏览，而不是按文件类型浏览。** Canto 要求主组织方式是项目或活动。面板主筛选仍是图片 / 视频 / 无声 / 文档。`job:` 能当标签筛，但不是默认结构。
6. **归档与保留期限。** Canto 要求定期审计后归档，而不只是去重。精确重复和近重复能查。没有冷归档、没有保留期限、没有定时清理。失效外链的清理仍是手动。
7. **审批流。** 商业治理是「未审批的版本不能分发」。本库的人工确认只挡 Agent 写库（`confirm=true`），没有提交、审核、通过、驳回。
8. **元数据模式本身。** Adobe 要求先写清每个字段的目标、用途、谁能改、有哪些取值。字段散在表和 sidecar 里，没有一份这样的模式说明。
9. **内容表现回流。** Aprimo / Agentic DAM 的学习闭环是看素材被用了多少、效果如何，再改推荐。现在只有 Agent 动作的采纳日志（`.agent_feedback.jsonl`），没有播放、选用、发布后的表现数据。

## 只对齐了一部分

10. **描述性元数据。** Adobe 要求入库时就有能说明内容的描述。技术事实（分辨率、时长、编码）已补到多数条目。真正说明画面里是什么的文字在 `index/visual/`，而且 9 条损坏视频抽不出帧；另一条开头是黑场，模型编造的描述已删。描述列里故意不写这些派生文字，避免再把词法门禁打下去。
11. **按镜头检索。** 商业视频检索按场景切段，每段单独索引。本库用台词或画面行上的时间，去对上已有镜头的起止，面板能跳到那一秒。没有给每个镜头单独做描述和向量。一条片子可以有几十个切点，逐镜跑视觉模型这次没做。
12. **以文搜图。** 商业产品把视觉搜索放进主结果。这里只有文字命中少于 3 条才补 CLIP，而且顶分要到 0.32、并比第二名高出 0.03，否则整批不要。原因是实测「鸡翅」会把红印章排到前面。多帧向量已有 84 / 93 条视频类素材，仍然走这条守卫。
13. **重排。** 商业 RAG 是召回之后用交叉编码器精排。代码在，默认关闭。本机 ollama 不提供重排接口，开了也会退回原来的名次融合。候选文本已经带上画面描述、OCR 和转写。
14. **台词检索的干净程度。** 转写已挂到同任务的视频和音轨，命中能跳时间。一句完整台词会带出一百多条结果，因为画面描述里的常用双字（如「一个」「问题」）也能得分。正确的片子排在最前，后面是噪声。
15. **查询意图。** 商业系统按「找文件 / 看画面 / 听台词」换通道和门槛。现在只识别路径、编号、`type:` / `job:`，以及句子里出现「台词 / 字幕 / 说了」。其余查询仍用同一个 0.25 余弦门槛。
16. **人脸之外的智能标签。** 自动标签曾写进主排序字段，词法精度下降，已撤回。现在的自动描述只写技术事实和任务号。物体级标签只在画面 sidecar 里，覆盖不完整。
17. **培训与季度演进。** Canto 的最后两条是给人做培训、按季度改分类法。仓库里有上手文档。没有培训记录，也没有固定的季度复核。

## 明确不做（单机、素材自产）

这些在商业清单里，但不适合当前这台机器上的自产素材库。写在这里是为了和「还没做」分开。

- 内容凭证 C2PA 签名
- 个人信息检测与脱敏
- 网关级权限（按人、按工具、按资源）
- 先整篇编码再切块的 Late Chunking
- 为多样性打散结果（结果集不大）
- 把查询拆成多步再检索（三百多条，用不上）
