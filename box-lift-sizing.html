矩阵读出来的四件事

观察含义
短任务下 350 与 200 完全一样 演示 / 园区两行里，提高能量密度一点用没有——因为都是功率受限。这是 A5 最直接的实证。
非系留方案最小机体 3.1 m 最好的混动也要 3.1 m；纯电 3.7 m；氢电 4.5 m。想紧凑（≤2.5 m）只有系留。
混动几乎不受任务时长影响 到 20 min 仍是功率受限（0.98 m 不变），是最稳健的方案；代价是功率 478 kW 偏高。
纯电随任务加长急剧恶化 10 km 通勤要 5.4 m、20 min 要 7.4 m —— 能量受限接管后直接不现实。

注：系留数学上任意直径都收敛，但盘太小会让功率荒谬（0.34 m 时需 1116 kW）， 所以按功率选取 0.6–0.8 m 才是工程上合理的。

两个能收敛的方向

排除「纯电 + 紧凑」后，实际只剩两条路。先看两张同一比例尺的对比图—— 右边明显大一圈，这就是「要自由飞行就得接受多大」的直观答案。 配置前提：6 涵道、载重 150 kg、悬停 5 min、余量 20%，机体外径 ≈ 3.2 × 涵道直径。

参照：B 的 3.84 m 直径，约等于一张双人床的宽度，或比紧凑型轿车（长约 4.2 m）略小一号的圆。 A 的 2.24 m 还像个「带护栏的座椅」，B 已经是一台小型飞行器。

注意侧视图的高度几乎一样（1.6 vs 1.8 m）——差别全在直径上。这正是为什么「看起来只是大一圈」， 物理上却从发散变成收敛。

盘做大 22%，总重反而降 39%、功率降 61%。原因：盘大 → 功率低 → 电池与推进双双变轻 → 总重下降。 所以「尽量做小」是错的，正确做法是在机体尺寸允许的范围内尽量取大盘。

差距清单 · 从「概念冻结」到「能飞行使用」

概念稿在「画什么」层面是闭合的（外形 / 操控 / 安全 / 人机 / 验证路径都已冻结）， 但「能不能飞」还差下列部分。分三层：A = 不改就飞不起来， B = 不改就飞不好 / 不安全，C = 不改就飞得起来也不能用。 下列门槛数据基于默认参数组（纯电 200 Wh/kg / 1200 W/kg、载重 150 kg、悬停 5 min）。

A 类 · 不改就飞不起来（物理硬门槛）

部分问题要改什么
A1 总盘面积 /
推进布局		 脚下 6 个小涵道仅 1.18 m²，盘载荷极高 → 功率爆炸 → 迭代发散。这是杠杆最大的一项。 涵道外扩 / 加大到 ≥1.2 m / 增加数量；盘面积翻倍 ≈ 功率降到 0.7 倍
A2 能源架构 纯电被功率密度卡死，短时都勉强；堆能量密度不减重。 三选一：混动增程 / 氢电（注意其功率弱点）/ 系留供电
A3 任务剖面 只写「载重 150 kg」，没写飞多久、多远 —— 数字一变，能源结论全变。 先冻结具体剖面：悬停几分钟 / 平移几 km / 每天几架次
A4 重量预算闭环 只有「空机 ≥100 kg」这类量级，算不出是否收敛。 出重量分配表并迭代收敛（本页即在做）；很可能收敛不出「纯电 + 150 kg」
A5 功率密度约束 此前完全没提，但它比能量密度更早卡死系统。 明确包级持续放电能力（W/kg）并作为硬指标

B 类 · 不改就飞不好 / 不安全

部分问题要改什么
B1 涵道在脚下的气动 进气被腿 / 座 / 护栏遮挡；下洗被地面反射；吹起异物 FOD；脚离涵道太近。 改侧进 / 上吸；涵道外移出人体投影；加格栅与裙边
B2 单通道失效可控性 6 个坏 1 个剩 5 个，不对称；剩余推力与控制权限从未算过。 做失效配平计算（任意 1 个 / 对角 2 个失效）；大概率需加整机弹道降落伞
B3 热管理 数百 kW 级持续放电；涵道是封闭腔，散热更差。 热预算 + 强制散热路径（又吃重量，要回写 A4）
B4 操纵品质与抗风 只写「微风隔离场地」，无量化指标；载人尺度惯性大。 定抗风等级、控制带宽 / 阻尼、视野（护栏遮挡）、眩晕与培训要求
B5 单涵道推力与结构 无推力分配与载荷路径。 由 A1 的盘面积反推单涵道推力，再做结构载荷

C 类 · 不改就「飞得起来也不能用」

部分要改什么
C1 法规与许可 类别认定、适航 / 豁免、试飞空域、保险、外部技术评审
C2 制造与质检 工艺、追溯、批次一致性、召回机制
C3 运营边界 开放街道 永久 No-Go；仅限隔离 / 许可场景

三条出路（按代价排序）

出路代价保留座椅外形
① 系留供电只能定点，缆绳限制活动范围可以
② 放大盘面积 ≥1.2 m机体变成 ~3.5–4 m；仍是纯电短航时否（变小飞碟）
③ 混动增程系统重、吵、复杂；盘载荷仍偏高否

若坚持「载人 + 自由飞行 + 紧凑外形」三者同时满足 → 当前物理下无解。

模型（量级，非设计文件）
推力 T = AUW · g · kT；理想诱导功率 P_ind = T^1.5 / √(2ρA)； 轴功率 P_shaft = P_ind / FM；电功率 P = P_shaft / η； 推进重量 = P / 推进功重比；电池重量 = max(能量需求 / 能量密度, P / 功率密度)； AUW = 载重 + 空机固定 + 推进 + 电池，迭代至收敛（或判定发散）。
功率密度指持续放电能力（非瞬时），决定电池能否输出所需 kW；能量密度决定能撑多久。 系留供电时功率来自地面，不受机上功率密度约束。
未计入：涵道唇口/支架损失、进气遮挡、地面效应、热管理重量、结构随载荷增重、操纵冗余裕度。 真实值通常比本模型更差。

本页 = 收敛速算 + 差距清单，均为概念级，非工程设计与选型文件，不能替代 CFD / 台架实测。速算的目的只是回答一个问题： 这个闭环收不收敛。 divergent（发散）= 加电池也救不回来，必须改构型或改能源。
