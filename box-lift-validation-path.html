隔离场地验证路径 · 七阶段门禁

台架 → 系留 → 无人 → 才谈载人。每一阶段都有进入门禁与通过判据， 任一阶段不通过，不得跳级。全程仅在隔离场地，开放街道不在路径内。

载重 150 kg 目标 非载人优先 系留为载人前强制门禁 门禁判据书面留档 跳过台架直接载人 开放街道验证
门禁三原则
  • 可并行、不可跳过：低风险准备可并行推进，但载人/销售必须由前序阶段全部通过解锁。
  • 判据先写后测：进入某阶段前先把"通过判据"写清并留档，禁止事后找理由放行。
  • 失败即回退：任一判据不达标 → 退回上一阶段，而不是放宽判据。
阶段 0

概念冻结

已完成

已交付

  • 构型冻结：坐姿舱 + 扁椭圆底 + 周向 6 涵道
  • 载重定义：人 + 物 ≤ 150 kg（空机另算）
  • 操控定义：人驾驶 + 飞控增稳（拒绝开环手拧）
  • 安全六层 L1–L6 写入需求基线

明确不在本阶段

  • 量产与销售承诺
  • DIY 施工步骤
阶段 1

非载人台架

唯一合理的下一步

进入门禁

  • 阶段 0 冻结完成
  • 有固连工装与隔离试验位
  • 测量与急停回路就绪，数据可记录回放

必做 / 必测

  • 整机固连于台架，人不坐
  • 升力逐级加载，测总推力 / 电流 / 电压 / 温升 / 振动
  • 长时间运行与反复起落循环
  • 六通道一致性与单通道失效行为观察

通过判据

  • 总升力 ≥ 起飞重量 × 1.3，且可复现
  • 温升、振动、电气参数在限值内
  • 结构无异常（无裂纹 / 松动 / 变形）
  • 全过程数据留档可复盘

No-Go

  • 人不得上台架或坐在机上
  • 不得因"看起来稳"跳过固连
门禁 未达 ×1.3 升力或温升超限 → 回退重新设计动力/散热，不进入系留。
阶段 2

系留悬停

需阶段 1 通过

进入门禁

  • 阶段 1 全部判据通过
  • 防坠索 / 系留装置就位
  • 高度与水平半径被物理限制

必做 / 必测

  • 带系留离地，仍不载人（配重替代）
  • 增稳手控悬停可复现性
  • 单通道失效降级演示 → 只许受控下降
  • 急停演示 → 受控降落

通过判据

  • 手控增稳悬停可稳定复现
  • 单通道失效 不翻，走受控下降
  • 急停链路可靠触地
  • 系留全程有效，无超限逃逸

No-Go

  • 不载人
  • 不解除系留
门禁 单通道失效出现不可控姿态或系留失效 → 回退阶段 1，不许自由飞。
阶段 3

无人包线

需阶段 2 通过

进入门禁

  • 阶段 2 全部判据通过
  • 遥控手控 + 地面急停双通道就绪
  • 场地边界、风限、高度上限已定义

必做 / 必测

  • 配重到目标起飞重量，仍不载人
  • 隔离场地内自由悬停
  • 包线策略固化：限高 / 限速 / 限倾角
  • 风限、低电压、姿态异常的否决行为验证

通过判据

  • 包线内飞行可复现
  • 超限指令被自动否决（只许降）
  • 地面急停可靠触地并闭锁
  • 环境边界（风限）有实测支撑

No-Go

  • 不载人
  • 不进开放街道 / 人群上空
门禁 包线否决或地面急停任一失效 → 回退阶段 2，不得进入监管沟通。
阶段 4

监管沟通

需阶段 3 通过

进入门禁

  • 阶段 3 实测数据与故障树
  • 安全六层与验证记录可提交

必做

  • 类别认定咨询（属于哪类航空器 / 试验体）
  • 试飞条件、空域与场地许可
  • 保险与第三方责任方案
  • 外部技术评审

通过判据

  • 取得书面许可路径与试飞条件
  • 评审意见已闭环

No-Go

  • 无书面许可 → 禁止载人
门禁 拿不到书面框架 → 项目停在无人验证，不载人。
阶段 5

载人试验

需 1–4 全通过 + 评审 + 许可

进入门禁

  • 阶段 1–4 全部通过并留档
  • 外部评审通过、许可在有效期内
  • 约束联锁、防坠、地面监控全部在位

必做

  • 低高度、限速、微风窗口
  • 优先保留防坠 / 系留条件
  • 乘员 briefing 与实体急停可达性确认

通过判据

  • 仅在监管框架内评估，不自我发证

No-Go

  • 缺任一门禁即禁止载人
  • 不得对外售票或宣传为体验项目
门禁 任一环节缺失 → 立即停飞并回退，不以"低空就安全"自我放行。
阶段 6

小批量 / 许可场景

需阶段 5 通过 + 持续合规

进入门禁

  • 阶段 5 通过且持续合规
  • 有量产一致性体系与召回机制

范围

  • 仅限许可场景（隔离园区 / 科研平台等）
  • 持续运行数据与故障上报

通过判据

  • 持续合规，无未闭环重大故障

No-Go

  • 开放街道永久 No-Go
  • 不得作为消费级"飞行座椅"销售
门禁 出现未闭环重大故障 → 全面停飞复盘，不靠软件补丁续飞。

场地安全矩阵（与阶段绑定）

阶段必须的安全措施
台架固连，人不坐
系留顶/侧防坠索，限制高度与水平半径
无人包线遥控手控 + 地面急停
载人讨论仅当上面全过 + 外部评审 + 许可框架

什么时候可以谈"载人"

前序状态
阶段 1 台架通过
阶段 2 系留通过
阶段 3 无人包线通过
阶段 4 监管书面许可
结论1–4 全绿才可进入阶段 5

没有场地门禁，只加护栏 = 假安全。
